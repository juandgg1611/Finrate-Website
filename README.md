# FinRate Website

Sitio web oficial de FinRate: app para convertir USD, EUR, USDT y bolívares con tasas del BCV y Binance P2P en tiempo real.

## Contenido

- `index.html`: página principal
- `privacy.html`: política de privacidad
- `terms.html`: términos y condiciones
- `css/`, `js/`, `assets/`: estilos, scripts e imágenes

## Despliegue

Sitio estático, sin proceso de build. En Netlify: build command vacío y publish directory `.` (la raíz del repo).
